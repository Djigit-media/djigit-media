Сборка: carousels/_kit/build.py (HTML/CSS по style.json + copy.json → Playwright + /usr/bin/google-chrome → slides/01..07.png 1080x1350, device_scale_factor 1). Обложка может быть видео-слайдом 5–7 с (ffmpeg, 1080x1350, H.264).
Проверки каждого кадра перед показом:
1. Размер 1080x1350, sRGB, без пустых и обрезанных текстов (сравнить DOM scrollWidth/clientWidth).
2. Поля 80 px, ничего не выходит за них; ничего не перекрывает лица и еду.
3. Висячих предлогов 0; текст слово в слово с copy.json.
4. Шапка, прогресс-бар (текущий этап подсвечен), подвал с «ХОЧУ ОТКРЫТЬ» на каждом слайде; финал с огромным словом-ключом.
5. Контакты и ссылки сверены с Пультом.
Выход: slides/01..07.png, preview.jpg (сетка 7 слайдов) + caption.txt. Публикация каруселью через Graph API (media_type CAROUSEL) только после «ок» Вала.
