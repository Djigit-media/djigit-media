# Оффер DJIGIT (метод @dashi_agent «Ваш продукт хорош. Почему не покупают?», https://www.instagram.com/p/DfvFYGzDfO_/)

## 0. Источники фактов (сверять в том же ответе, иначе не писать)
1. Сайт djigit.biz (WebFetch). 2. Документы Вала «DJIGIT Franchise EU», «DJIGIT Franchise UA». 3. «KHINKALI HOUSE — паспорт продукта». Расходятся: одна строка Валу, какую версию брать. Своих названий форматов не придумывать.

## 1. Воронка: где теряются покупатели
Считать каждую неделю: просмотры → «ХОЧУ ОТКРЫТЬ» (комментарии и директ) → ответ отправлен → созвон → договор. Почему уходят: неясный результат, мало доказательств, непонятный первый шаг.

## 2. Навык «Оффер»: 12 пунктов (каждый оффер проходит все)
Ясный результат · Для кого продукт · Разбор сомнений · Что входит · Понятный старт · Честные условия · Одна сильная фраза · Реальные факты · Первый результат · Что не обещаем · Следующий шаг · Проверка на клиентах.

## 3. Проверка на задачах, а не красивой оценкой
3 задачи (ролик, карусель, ответ в директ) × 3 критерия (ясность, факты, первый шаг). Каждая ячейка «готово / доработать». Побеждает вариант, который выдержал проверку.

## 4. От «не покупают» к разбору в 4 шага
1) Найти слабое место. 2) Разобрать возражения. 3) Проверить ценность (результат, доверие, скорость, простота). 4) Собрать новую версию.

## 5. Возражения покупателя франшизы: фраза → вопрос → следующий шаг
- «Я подумаю» → «Что мешает решиться?» → уточнить риск.
- «Дорого» → «Понятен ли результат?» → показать ценность (окупаемость, прибыль по формату из документов Вала).
- «Сделаю сам» → «Где нужна наша помощь?» → объяснить сопровождение под ключ.
- «Что я получу?» → «Можно представить итог?» → показать результат (что входит, первый месяц).
Ответы только фактами из источников п.0.

## 6. Пересборка предложения (таблица)
Продукт · Для кого · Результат · Первый шаг · Границы (что не обещаем). Сначала разбор, потом готовый текст.

## 7. Подача в контенте (как у эталона)
Карусель 9 слайдов, 7 из них видео-слайды с анимацией интерфейса (HyperFrames: npx -y hyperframes, проверено 0.9.104), подвал на каждом слайде «Пиши «ХОЧУ ОТКРЫТЬ» в комментариях…», финал с огромным словом-ключом.
